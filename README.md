# Rabin KC

I study computer science at Gettysburg College and build apps and games. I’m interested in testing how people use what I build and making the experience clearer.

## Projects

- **Food101** helps people decide what to cook with the ingredients they have. It combines pantry-based recipe matching, a meal planner, and guided cooking. [Try the live beta](https://food101-sand.vercel.app/).
- **Poker Night** is a browser-based Hold’em game in development with a solo career, private multiplayer rooms, and a lab for replaying table scenarios.
- **Apollo** is a music player I built to practice UI/UX design. It displays lyrics synchronized to playback from imported `.lrc` files.
- **Skybound** is a 2D Godot prototype where I explored movement and combat. Development is on hold.
